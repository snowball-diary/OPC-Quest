为什么选 Prisma

在桌面应用开发中，本地数据库的选型一直是个让人头疼的问题。SQLite 轻量但手写 SQL 繁琐，IndexedDB 灵活但调试困难。

项目初始化

首先创建 Electron 项目并安装 Prisma 依赖：

mkdir electron-prisma-demo && cd electron-prisma-demo
npm init -y
npm install electron prisma @prisma/client

踩过的坑

  • query engine DLL 被锁定: 需要先 kill electron 进程
  • Date 对象序列化: IPC 传输时会变成 string
  • 路径问题: 需要用 app.getPath('userData')

总结

Prisma + Electron 是本地优先桌面应用的优秀组合，类型安全 + 迁移管理让开发体验非常流畅。
